## 2. 알고리즘 — Midpoint Displacement Bolt (게임 그래픽 고전 기법)
1. **본줄기**: 총구→명중점 직선을 재귀 이등분 4~5회. 매 분할마다 중점을 **볼트 축에 수직인 평면 내 랜덤 방위각**으로 변위 — 변위량 = 세그먼트 길이 × 0.12~0.18, 재귀마다 절반으로 감쇠. (수직 평면 내 랜덤 방위 = 진짜 3D 지터. 화면 평면에만 흔들면 납작해 보임)
2. **곁가지**: 내부 정점의 ~30% 확률로 가지 생성 — 방향 = 부모 진행방향 ±20~40° 회전, 길이 = 남은 본줄기의 0.3~0.5, 두께/밝기 60%, 1단 재가지 허용(확률 절반). 가지도 같은 변위 재귀 2~3회.
3. **렌더 2패스 (가산 블렌딩)**:
   - 외곽 글로우: 두껍고(코어의 3~4배) 알파 낮게, 색 = 게임 네온 팔레트(시안 #19f0ff ↔ 보라 계열 그라디언트)
   - 코어: 가늘고 거의 백색, 알파 높게
   - ⚠️ WebGL에서 `linewidth`는 Windows(ANGLE)에서 안 먹는다 — 두께는 **빌보드 쿼드 스트립**(세그먼트당 카메라를 향하는 사각형)으로 구현하거나, 이 게임이 기존 빔/파티클에 쓰는 방식을 재사용하라. 기존 렌더러 관례 우선.
4. **애니메이션**: 볼트 생존 시간 80~120ms. 그동안 40~60ms마다 변위 재롤(플리커) + 알파 ±20% 흔들기 + 마지막에 페이드아웃. 명중점에 짧은 임팩트 플래시(기존 폭발/파티클 재사용 가능하면 재사용).
5. **성능**: BufferGeometry 풀 재사용(볼트마다 새 지오메트리 할당 금지). 세그먼트 캡: 본줄기 ≤32 + 가지 ≤24 = 볼트당 ~60. 동시 볼트 캡 4 (오디오 폴리포니와 일치). 연사 시 프레임 드랍 없어야 함.
