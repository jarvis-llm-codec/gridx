## 2. SFX — 스코프 주의 (Jun 명시 지시)
**효과음은 전부 기존 신스 그대로 유지. 딱 하나만 교체한다:**
- **라이트닝 무기 발사음** → `assets/sfx/lightning.ogg` (1.2s, 존재함. CC0 파생물 — 세부는 `assets/sfx/candidates/LICENSES.md`)
- 구현: 샘플 원샷 재생기 1개 추가 (Web Audio buffer).
  - **폴리포니 제한 필수**: 라이트닝은 연사 무기. 동시 재생 캡(권장 3~4 보이스) + 최소 발동 간격(권장 60~90ms). 캡 초과 시 가장 오래된 보이스 컷.
  - 기존 신스 SFX와 동일한 **팬닝 규칙**(플레이어 x좌표 기반) 적용.
  - 볼륨 config 노출 (권장 기본 0.55 — 신스 SFX 대비 튀지 않게 실청 밸런스).
  - 파일 로드 실패 시 **기존 신스 라이트닝 소리로 폴백** (무음 금지).
  - 뮤트(M) 연동.
- 다른 무기·폭발·픽업·피격음은 절대 건드리지 마라. (라운드 2 본편지 Fix B의 "신스 파라미터 원본 복원"은 그대로 유효 — 이 부록은 그 위에 라이트닝 1건만 샘플로 얹는 것)
